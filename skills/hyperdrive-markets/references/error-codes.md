# Error codes

| ID  | Name                                  | Description                                                                                                                                                                                                                   |
| --- | ------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 0   | `ERROR_CODE_INVALID_INPUT`            | A parameter failed validation: a zero address or amount, a fee above `MAX_FEE`, a hook or risk model that isn't a contract, `notional < equity`, an unknown subscription or redemption ID, or merging a position into itself. |
| 1   | `ERROR_CODE_UNAUTHORIZED`             | `msg.sender` doesn't have the operator permission flags the position needs for this action (withdraw, subscribe, redeem or borrow).                                                                                           |
| 2   | `ERROR_CODE_UNHEALTHY_ACCOUNT`        | The action would push the position over its LTV limit: the safe LTV for withdraw, borrow, merge and subscribe sizing, and the liquidation LTV for redeem.                                                                     |
| 3   | `ERROR_CODE_HEALTHY_ACCOUNT`          | `liquidate` was called on a position that is still inside its liquidation LTV, so it can't be liquidated.                                                                                                                     |
| 4   | `ERROR_CODE_INSUFFICIENT_LIQUIDITY`   | `subscribeCollateral` asked for more debt than the market holds in idle assets.                                                                                                                                               |
| 5   | `ERROR_CODE_INVALID_REDEMPTION_RATE`  | The adapter returned a redemption rate of 0.                                                                                                                                                                                  |
| 6   | `ERROR_CODE_RATE_TOO_HIGH`            | The risk model returned an interest rate above `WAD` (100%), raised in `RiskModelLib.safeRate`.                                                                                                                               |
| 7   | `ERROR_CODE_SUBSCRIPTION_ACTIVE`      | The position has a subscription still in progress, which locks it against subscribe, redeem, borrow, repay, merge and liquidate.                                                                                              |
| 8   | `ERROR_CODE_SUBSCRIPTION_NOT_ALLOWED` | `subscribeCollateral` was called on a position that still has debt; subscriptions need a position with no debt.                                                                                                               |
| 9   | `ERROR_CODE_REDEMPTION_ACTIVE`        | The position has a redemption still in progress, which locks it the same way as code 7 and also blocks `supplyCollateral` and `withdrawCollateral`.                                                                           |
| 10  | `ERROR_CODE_INSOLVENT`                | The market has shares outstanding but zero total supply assets, so deposits and withdrawals are blocked.                                                                                                                      |
| 11  | `ERROR_CODE_CANNOT_BE_COMPLETED`      | An async ERC7540 subscription or redemption can't be claimed yet: the adapter reports less claimable than the balance held, or a singleton queue request isn't `FINALIZED`.                                                   |
